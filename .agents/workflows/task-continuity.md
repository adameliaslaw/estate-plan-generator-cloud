# Task Continuity

When the user sends a message while you are in the middle of an active task:

1. **If the message is about the current task** — acknowledge it and continue working, adjusting your approach based on their feedback.

2. **If the message is a new request** — finish the current step if close to completion, then switch to the new request. Update task.md to reflect the change.

3. **If the message is a clarifying question** — answer it directly and continue with the task.

4. **Never ignore the user's message** — always acknowledge it even if you're mid-task.
